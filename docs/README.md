# yosage-dev-leader-harness の使い方

yosage-dev-leader-harness は、ハーネス本体 `yosage-dev-harness` が前提の**拡張**です。単独では動きません。
本体を同じ案件で有効にしたうえで足すと、メインのセッションが「実装者を統制するリーダー」として振る舞う
ようになります。

- 本体が受け持つのは、実装役への投入、draft PR、一次レビュー、人によるマージといった**実装の流れ**です。
  本体の使い方は、ハーネス本体の使い方（本体の `docs/`）を見てください。
- この拡張が足すのは、その手前と周辺です。要望を受け入れ条件つきの要件にする、作業の順序を決める、実装役
  への指示を書く、判断を裁く（前例があれば自分で、無ければ人へ上げる）、マージの推奨を述べる、といった
  役割です。

このドキュメントは、本体の流れを知っていることを前提に、**拡張を足したときの差分**だけを書きます。
導入の手順や収録しているスキルの一覧は、リポジトリの `README.md` にあります。

## 用語

- **リーダー**: 案件のメインセッション。要件化・裁定・投入指示を行い、実装はしません。
- **実装役（作業部隊）**: 本体の `yosage-dev-harness:implementer` などのサブエージェント。割り当てられた1つの
  作業単位を実装します。
- **人**: 案件の利用者。クライアントや PO とつながる人でもあります。この拡張の文書では、一段上の主体を
  「上位」と呼ぶ箇所があります。現状、上位に居るのは人です。
- **規律スキル**: リーダーが判断の前に読み込む取り決め。`/` のメニューには出ません。
